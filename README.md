# dictate

Run `dictate.cmd` (or `python -m dictate.app`) to start the tray app; it refuses to start if Wispr Flow is still running.
The tray icon (the green mic tile) is the on/off switch, like Wispr's: left-click it to turn dictation off -- the icon greys out, the hotkeys stop and the mic is released, so the Windows mic indicator disappears -- and click again to turn it back on. Right-click for **Dictation on**, **Language** (English / Polish / Auto), **Start with Windows**, **Open settings folder** and **Quit dictate**. It always starts on. Tray errors go to `%APPDATA%\dictate	ray.log`.
If your taskbar hides new tray icons, promote it: Settings → Personalisation → Taskbar → Other system tray icons → **Python** on.
**Language** (24 Sept): Parakeet v3 hears Polish on its own (it auto-detects; sherpa-onnx has no language pin), so the setting picks the cleanup prompt -- `en` uses `prompts/cleanup.txt`, `pl` uses `prompts/cleanup_pl.txt` (Polish fillers, diacritics, Polish comma rules, zł, never translates), `auto` picks one per clip from Polish letters or common Polish words. Set it from the tray menu or `language: en|pl|auto` at the top level of `config.yaml`; default `en`. Verbatim apps (VS Code, Cursor, terminal) are unaffected. Test clips: `bench/pl/*.wav` (edge-tts, gitignored); unit tests: `python tests/test_language.py`.
**Spoken instructions** (25 Sept): start a sentence with **"Dictate,"** anywhere in a clip to tell the editor how to write it -- "Dictate, make this bullet points", "...Dictate, make it more formal", "Dictate, turn this into a bug report with a title". The clip then goes to `prompts/instruct.txt` instead of the cleanup prompt, the instruction is applied and removed, it runs even in verbatim apps, and it gets `instructions.budget_s` (6 s) and `instructions.model` (Gemini 2.5 Flash, ~$0.0004 a clip -- Flash-Lite turned list items into headings) instead of the usual budget and model. "Dictate" works anywhere in the clip, in English or mid-Polish ("Jeszcze raz, dictate."); "bullet point(s)" means one bullet per item. If the LLM fails, the "Dictate, ... ." sentence is stripped before pasting. Trigger word(s), on/off and budget live under `instructions:` in `config.yaml`; history logs these clips as `ok:instructed` (or `skipped:*:instructed`). Detection: `dictate/instruct.py`, tests: `tests/test_instruct.py`.

Hold **Right Shift** (or **Ctrl+Win**) to record, release to transcribe and paste; **Ctrl+Win+Space** toggles hands-free recording without holding the keys; **Escape** while recording cancels the clip. All of these keys can be changed in tray → **Settings (keys and clean-up)...** (stored in `config.yaml` under `hotkeys:`).
Run `python -m dictate.app --autostart` to add a shell:startup shortcut (`--no-autostart` removes it), `python -m dictate.app --desktop-icon` to put the same shortcut on the Desktop (`--no-desktop-icon` removes it), and `python -m dictate.app --doctor` to check mic, model, API key, hotkey hook and Wispr status.
Both shortcuts run `dictate.cmd`, which is a no-op if the app is already up, and wear `assets/dictate.ico` (regenerate with `python assets/make_icon.py`).
Started from a Claude desktop session, the app relaunches itself through `explorer.exe` and exits: Claude is an MSIX package, and anything it spawns has its `%APPDATA%` writes redirected into `%LOCALAPPDATA%\Packages\Claude_pzs8sxrjxfjjc\LocalCache\Roaming`, which the shortcuts never see (24 Sept: the model lived only there, so the Desktop icon died silently). `--doctor` run from a session sees that merged view, so check the real side with `explorer.exe some.cmd` instead.
Your dictionary, snippets, per-app policy and cleanup settings live at `%APPDATA%\dictate\dictionary.yaml`, `snippets.yaml`, `apps.yaml` and `config.yaml`.
To add a word or correction, add a row to `dictionary.yaml` (`phrase:` for casing fixes, plus `replacement:` to substitute what was said) or a `trigger:`/`text:` pair to `snippets.yaml` -- picked up on the next clip, no restart needed.
Cleanup (LLM grammar/punctuation pass) is done by whoever tray → **Settings** names (`cleanup.provider`): an OpenRouter key (default, free models), a Claude API key (Haiku 5.5), an OpenAI API key (gpt-5.4-mini), or the person's own Claude or ChatGPT plan through the Claude Code / Codex CLI (`claude-app`, `codex-app`: ~10 s a clip, no key). With OpenRouter it uses a free model by default; set `cleanup.model` in `config.yaml` to a paid OpenRouter model id (e.g. `nvidia/nemotron-3-super-120b-a12b`) to use that model instead, or `cleanup.enabled: false` to turn cleanup off entirely (vocabulary pass only).
`Code.exe`, `Cursor.exe` and `WindowsTerminal.exe` always get the verbatim (no-cleanup) pass; edit `apps.yaml` to change which apps get which.
Only Notepad is exercised by the automated proof (`tests/test_e2e_notepad.py`) -- an agent can't speak, and this desktop is in daily use, so the Claude app / Brave / VS Code checks are for you to try by voice.
Every clip's `e2eLatency`, `asrText`, `formattedText` and `cleanup` status are logged to `%APPDATA%\dictate\history.sqlite`, so those checks can be read back afterwards even though they weren't run here.

Paid cleanup example: `config.yaml` → `model: google/gemini-2.5-flash-lite`, `budget_s: 1.5`, `e2e_target_s: 2.2` (≈ $0.0001 per clip, ~8p/month). Set `model: null` and `e2e_target_s: 1.4` to go back to the free chain.

22 Sept: engine switched to the int4 weight-only Parakeet build (`%APPDATA%\dictate\models\parakeet-tdt-0.6b-v3-int4`, better on this quiet laptop mic — "WordPress" not "Waterplace"); cleanup prompt rewritten to remove all fluff and fix grammar/spelling hard; transcript fenced so the model edits it instead of answering it; `google/gemini-2.5-flash` is the automatic second try. Budget 2.0 s, e2e target 3.0 s.

**Length check** (25 Sept): does dictate make more mistakes on long clips? Double-click `lengthcheck.cmd` (or `python -m dictate.lengthcheck test`) to read five passages aloud at ~17, ~42, ~82, ~135 and ~197 words; each take is scored against the text three ways -- what Parakeet heard, what it hears when the same audio is cut into ~12 s clips, and what would have been pasted after cleanup under the live budget. Takes and audio go to `%APPDATA%\dictate\lengthcheck.sqlite`; `lengthcheck.cmd report` prints the results plus your real history bucketed by length (cleanup landed / timed out, wait, words cleanup changed). Run it from Explorer or a normal terminal, not a Claude session (MSIX would hide the results file). Each take costs one cleanup call, ≈ $0.0001; `--no-cleanup` skips it. `python tests/proof_lengthcheck.py` runs the same chain on an edge-tts voice into `proof/lengthcheck-tts.sqlite`.

## Building the installer

`packaging\build.cmd` builds `build\installer\dictate-setup-<version>.exe` (about 32 MB): PyInstaller makes a no-Python app folder (`packaging\dictate.spec`), then Inno Setup 6 wraps it (`packaging\dictate.iss`). Set `PY` to a Python that has `requirements.txt` plus `pyinstaller` installed. The installer is per-user (no admin prompt) into `%LOCALAPPDATA%\Programs\dictate`, with Start menu, optional Startup and Desktop shortcuts, and an uninstaller. It never touches `%APPDATA%\dictate` (settings, key, history, model), so upgrades and uninstalls keep them. The speech model is not bundled; it downloads on first start. Windows shows "unknown publisher" once (no code signing): **More info -> Run anyway**.

**Releases:** bump `__version__` in `dictate/__init__.py`, commit, then `git tag vX.Y.Z` and `git push origin vX.Y.Z`. GitHub Actions builds the installer and attaches it to a GitHub Release. There is no auto-updater: to update a PC, run the new setup over the old install. It replaces the app and keeps everything in `%APPDATA%\dictate`.

`dictate.exe --selftest some.wav` transcribes the clip into `some.wav.txt` and exits, which proves the built app can recognise speech without a mic.

## Installing on another PC from source

1. Install Python 3.12 (64-bit) and copy or clone this folder.
2. `python -m pip install -r requirements.txt`
3. Run `dictate.cmd`. On first start the speech model (about 720 MB) downloads by itself, and the tray tooltip shows progress. Hold Right Shift once it says it's ready. To download it ahead of time instead, run `python -m dictate.models`.
4. Tray menu → **Settings (keys and clean-up)...** to pick a clean-up provider and paste its key. It's optional: without a key, clips paste as raw text. The key is stored in `%APPDATA%\dictate\secrets.env` on that PC only.
Each PC keeps its own settings, key and history in `%APPDATA%\dictate`; nothing is shared between PCs.

Only one dictate runs at a time (a named mutex). `python -m dictate.app --version` prints the version.
